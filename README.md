# Sergio Gonçalves — Consultoria Contábil

Site institucional publicado em https://www.sergiogoncalvescontabil.com.br/

Este repositório contém apenas o pacote do site já gerado (`site.tar.gz`) e o fluxo que o publica no GitHub Pages (`.github/workflows/publicar.yml`). O código-fonte e a documentação do projeto ficam fora deste repositório.

Para atualizar: gerar a versão de produção no projeto-fonte, substituir `site.tar.gz` e `site.tar.gz.sha256` e enviar para a branch `main`. A publicação acontece automaticamente.

Desenvolvido por [Orlando Marketing e Branding](https://orlandomarketingbranding.com.br/).
